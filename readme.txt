CHOTU BIRTHDAY WEBSITE

1. Open index.html in a browser.
2. For the 4-5 photos, tap each photo frame and choose an image from your device.
3. The selected photos are shown locally in the browser and are not uploaded anywhere.
4. To add music, place your legally obtained audio file in this folder and change the audio element in index.html from:
   <audio id="song" loop></audio>
   to:
   <audio id="song" loop src="your-song-file.mp3"></audio>
   Browser autoplay rules mean the music starts only after she taps "Open your gift".
5. You can edit the text directly in index.html.
6. To put it online, upload the folder to a static hosting service such as GitHub Pages, Netlify, or Vercel.
